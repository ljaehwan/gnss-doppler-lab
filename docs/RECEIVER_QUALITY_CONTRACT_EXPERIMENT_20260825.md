# Receiver-quality contract experiment — 2026-08-25

## Question

Does segment-safe sequence construction change existing frozen PRN-GRU scores,
and are any changes traceable specifically to receiver loss/reacquisition
boundaries?

This is a data-contract experiment, not a claim that receiver quality
conditioning already improves the final WCL detector.

## Frozen setup

- Model: `artifacts/ai_morph_gru_cleanStatic_q70_frame/prn_local_gru_predictor.pt`
- Model SHA-256:
  `f171bf0b2084e617c15ab6af72ef930539a4b8fddb120b5aa8f43a6339c96a6b`
- External case: TEXBAT DS8, 1.0 s windows, 0.5 s stride
- Official onset used for the audit: 110 s
- GRU history: 12 windows
- Residual, standardizer, thresholds, and frozen weights were unchanged

The audit is reproducible with
`scripts/audit_receiver_quality_score_contract.py`. The new scores are
generated by `scripts/score_texbat_prn_node_gru.py --stride-s 0.5`.

## Decision effect

The table applies the same frozen node thresholds to legacy and segment-safe
event aggregates.

|---|---:|---:|---:|---:|---:|
| max q90 | 719 | 708 | 11 | 11 | 0 |
| max q95 | 682 | 670 | 12 | 12 | 0 |
| max q99 | 288 | 288 | 0 | 0 | 0 |
| top-3 q90 | 655 | 645 | 10 | 10 | 0 |
| top-3 q95 | 620 | 611 | 9 | 9 | 0 |
| top-3 q99 | 258 | 258 | 0 | 0 | 0 |
| max q99.5 | 42 | 41 | 1 | 0 | 1 |
| max q99.9 | 20 | 20 | 0 | 0 | 0 |

Every decision flip occurred at a time bin containing a removed
boundary-crossing PRN score; there were zero flips outside those bins. The
largest shared-row RMSE difference was 8.41 × 10^-5, attributable to
different inference batch composition, and did not create any off-boundary
decision flip.

At q90/q95, segment safety removes 9–12 pre-onset flags without losing a
post-onset flag. At q99, the decision trace is unchanged. At q99.5, one
post-onset flag is removed, so the change is not uniformly beneficial across
all operating points.

## Negative controls

TEXBAT cleanStatic, TEXBAT DS4, and OAKBAT OS1–OS4 each had one uninterrupted
receiver segment per observed PRN in the cached 1.0/0.5 s tables. For all six
cases:

- segment-safe and legacy score row counts were identical;
- no boundary-crossing row was removed;
- all emitted histories satisfied the same-segment invariant;
- shared RMSE values agreed to ordinary floating-point batch tolerance.

This confirms that the contract is inert when no receiver boundary exists.

## Interpretation for the paper

The defensible result is narrow:

1. Legacy grouping by only `(run_id, prn)` can create invalid temporal
   histories after receiver gaps and reacquisition.
2. A receiver-state contract detects those boundaries without using attack
   labels or attack-sensitive residual features.
3. On DS8 it removed exactly the mathematically expected 60 invalid samples,
   and all decision changes were localized to those boundary bins.

This is necessary infrastructure for the next experiment—calibrating residual
tails by tracking-age/reacquisition state—but it is not yet evidence that such
conditioning improves the strict q99 WCL operating point.
