# Figures

## Manuscript figures

Both WCL figures are vector PDFs generated by one deterministic script:

- generator:
  [`../../../scripts/plot_wcl_cgc_figures.py`](../../../scripts/plot_wcl_cgc_figures.py)
- source/hash manifest:
  [`../../../docs/results/figures/wcl/wcl_cgc_figure_manifest.json`](../../../docs/results/figures/wcl/wcl_cgc_figure_manifest.json)

| Paper asset | Role | Output |
|---|---|---|
| Fig. 1, CGC principle | Nine-tap signed delay and cross-satellite geometry fit | [`wcl_cgc_principle.pdf`](../../../docs/results/figures/wcl/wcl_cgc_principle.pdf) |
| Fig. 2, evidence | Matched mechanism, tap aperture, JammerTest, and OpenIF panels | [`wcl_cgc_evidence.pdf`](../../../docs/results/figures/wcl/wcl_cgc_evidence.pdf) |

Rebuild from the repository root:

```bash
.venv/bin/python scripts/plot_wcl_cgc_figures.py
```

Fig. 1 reads the fresh receiver--RF pair `fv2-static-01`. Fig. 2 reads the
matched-profile summary, aperture summaries, JammerTest timeline, and OpenIF
S1/S2 summaries. Exact input SHA-256 values are recorded in the figure manifest.
